# 任务分工（Gemini / Grok bot）

前提：先读同目录 `二开方案.md`。仓库 `F:\claude bf\openclash ssh\libredesk`（Gemini 本机）；Grok bot 在自己的云主机上 `git clone https://github.com/abhinavxd/libredesk`（提交 `f4916f41`），改动以 patch/PR 形式交回。

分工原则：Gemini 在本机有完整仓库和工具链（Go 1.26、Node 24、pnpm 10），负责**改代码、跑测试**；Grok bot 的云主机适合**起 Postgres/Redis 做集成测试与人工验收**、以及不依赖本机状态的独立任务（模板中文化）。两边都不许改 `i18n/en-US.json` 以外的上游语言包（zh-CN.json 除外，已由 Claude 补全）。

每个任务的交付物 = 分支名 + 改动文件列表 + 测试证据（命令与输出）。做完在群里回一句「T<编号> 完成，分支 xxx，证据 …」。
