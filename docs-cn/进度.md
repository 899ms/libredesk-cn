**K6 完成（海外依赖排查）**
命令：`grep -rnoE "https?://...(googleapis|gstatic|jsdelivr|unpkg|cdnjs|fonts\.|youtube|gravatar|...)" frontend/apps frontend/shared-ui static internal cmd`
结论：**前端与静态模板没有任何海外 CDN / Google Fonts 引用**，字体和 JS 全部打包在本地。仅有三类外部地址：
1. `https://docs.libredesk.io/...` / `https://libredesk.io/` —— 后台各页的「文档」链接和页脚「Powered by」。国内可能打不开但不影响功能；K2 中文化时可把页脚链接改成自己的。
2. `https://updates.libredesk.io/updates.json`（`cmd/updates.go`）—— 启动时检查新版本。部署时 `config.toml` 设 `check_updates = false` 即可，不必改代码。
3. `https://www.googleapis.com/oauth2/...`（`cmd/oauth.go`、`internal/inbox/channel/email/oauth/`）—— 只在配置 Gmail OAuth 收件箱时才会请求，不配置就不会触发。
遗留：无需替换方案。
